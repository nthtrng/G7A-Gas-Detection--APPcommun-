# Gas Rover Monitoring Website

This project is part of the Joint Project.

Our group focuses on gas detection for a rover concept able to sense dangerous components in the air, gas, humidity, and environmental conditions.

## Features

- Homepage
- Database connection
- Sensor management page
- Gas observation display page
- Future dashboard with graphs and alerts

## Deployment

The website is deployed on Hangar from GitHub and connected to the shared database using environment variables.
